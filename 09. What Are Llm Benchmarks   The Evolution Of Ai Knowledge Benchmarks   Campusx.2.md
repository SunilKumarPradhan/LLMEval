## 🎯 Overview {#overview}

This part of the lecture continues the deep-dive into **LLM Benchmarks**, focusing on two historically important benchmarks:

1. **MMLU (Massive Multitask Language Understanding)** — the most dominant knowledge benchmark from 2021-2024.
2. **TruthfulQA** — the benchmark that introduced the world to the idea that *"more capable ≠ more truthful/aligned"*.

It also briefly introduces the **AGI Eval** philosophy before moving to the next benchmark.

> **Why this matters:** Understanding the lifecycle of a benchmark (rise → peak → saturation → retirement) helps you evaluate *why* newer benchmarks like GPQA and HLE replaced MMLU, and why blindly trusting a benchmark score is dangerous.

## 🕰️ MMLU — History and Evolution {#mmlu-history}

> **MMLU (Massive Multitask Language Understanding)**: A benchmark designed to test the **breadth of knowledge** of an LLM across 57 subjects.

### Why MMLU became the marketing standard (2021-2024)
Every LLM released between 2021-2024 used **MMLU accuracy score** as its primary marketing metric because at that time, MMLU was considered the best available benchmark.

### Timeline

| Year | Event |
|------|-------|
| **Sept 2020** | MMLU paper released. GPT-3 tested → scored **43.9%**. Human experts scored **~90%** on same dataset → huge gap shown between LLMs and humans. |
| **2021-2022** | **Peak usage period**. This was the era of the **Scaling Law** — companies simply kept increasing parameters (175B → 350B → 650B...) expecting capability to scale automatically. Models like **Gopher, Chinchilla, PaLM** registered scores here. |
| **2023** | **GPT-4** arrives and scores **86%** — very close to human experts (90%). MMLU's decline begins from here. |
| **2024** | All frontier models (Google, Anthropic, OpenAI) clustered in the **86-92%** range. Nobody could cross 92%. It became hard to differentiate models. |
| **2024 (study)** | Experts manually reviewed questions and found **~6.5% of the 14,000 questions were flawed** (wrong answers or missing correct options) — explaining why no model could exceed ~92-93%. |
| **2025** | Frontier labs **officially stopped using MMLU** (declared saturated/retired). By this time, **GPQA** and **HLE** had already emerged as replacements. |

### 🧠 Key Insight: The Scaling Law Era
> **Scaling Law Era**: The period (2021-22) where AI labs believed simply increasing model parameters would proportionally increase capability — "bigger is always better" mentality, without much architectural innovation.

## 📝 MMLU — Task and Dataset Details {#mmlu-task}

### Sample Question Structure
- MMLU questions are **multiple-choice** (4 options: A, B, C, D)
- Example: A **college physics** level question about muon decay lifetime (10⁻⁶ seconds)
- Each question comes with the correct answer labeled in the dataset

### The Task
1. Model is given a question + 4 options in the prompt
2. **5 example (few-shot) solved questions** are also sent along
3. Model must predict the correct answer (A/B/C/D)
4. **Accuracy score** = (correctly answered questions) / (14,000 total questions)

```
Total Questions: 14,000
Subjects: 57
Categories: 4 (Humanities, Social Science, STEM, Others)
```

## ⚙️ MMLU — Scoring Methods {#mmlu-scoring}

There are **two ways** to extract the answer from a model:

### Method 1: Generated Text
Model directly **prints/generates** a character output: "A" or "B" or "C" or "D".

### Method 2: Log Probability (Log-Likelihood)
Instead of generating text, you extract the **log probability** the model internally assigns to each option (A, B, C, D) as the next token, and pick whichever has the **highest probability**.

> This relates to how transformers work — whenever a token needs to be predicted, the model assigns a probability distribution over its entire vocabulary/search space. We take the **log of that probability** to determine the most probable answer choice.

### Why the difference matters
These two methods **do NOT give exactly the same score** — typically a **1-3 point difference**.

**Example (GPT-4 on MMLU):**
| Method | Accuracy |
|--------|----------|
| Generated Answer | 84% |
| Log Probability | 87% |

> ⚠️ **Takeaway:** Always check *which method* was used to report a benchmark score before comparing two models — a 2-3% "improvement" might just be a difference in scoring methodology, not actual capability!

## 📊 MMLU — Metrics {#mmlu-metrics}

Two types of accuracy are reported:

1. **Overall (Macro) Accuracy** — combined score across all 14,000 questions / 57 subjects
2. **Per-Subject (Micro) Accuracy** — separate accuracy score for each of the 57 subjects (e.g., Biology: X%, Physics: Y%, Law: Z%)

Both give different insights — overall accuracy shows general capability, per-subject accuracy shows subject-specific strengths/weaknesses.

## 🎯 MMLU — Prompt Sensitivity {#mmlu-prompt}

> **Format Sensitivity**: MMLU's accuracy score is **highly sensitive** to how the system prompt is written.

### Key Facts:
- Wording/terms used in the system prompt can significantly swing the accuracy score
- Many labs have been accused of **"prompt gaming"** — inserting specific keywords that inflate scores
- Using the **same exact prompt** across models is critical for fair comparison — changing prompts even slightly can change scores for the *same model*

### Additional Factors
| Setting | Standard Value | Notes |
|---------|----------------|-------|
| **Chain of Thought (CoT)** | Not allowed (by default) | If allowed, performance may be marginally better since model "thinks" longer |
| **Shot type** | 5-shot prompting | 5 solved examples shown before the actual question |
| **Reasoning** | Direct | No CoT triggering |
| **Temperature** | 0 | Deterministic output |
| **Pass@k** | Pass@1 | Question shown once, one answer taken |
| **Tools** | Not allowed | No internet/compiler access — would make the test trivial |

## 🚫 MMLU — What It Does NOT Measure {#mmlu-limitations}

> **Core principle**: MMLU strictly measures **breadth of knowledge**, nothing else.

| Not Measured | Explanation |
|--------------|-------------|
| **Reasoning Depth** | MMLU is NOT a good benchmark to test reasoning capability |
| **Calibration** | Does not test whether the model "knows that it knows" — no truthfulness check mechanism |
| **Open-ended Retrieval** | Since it's multiple-choice (pick 1 of 4), it never tests free-form answer generation |
| **Multilingual Ability** | English-only, exam-style, mostly Western curriculum-based — poor benchmark for testing Chinese/Indian knowledge domains |

## ⚠️ MMLU — Known Issues & Criticism {#mmlu-issues}

1. **Label Errors**: ~6.5% of the 14,000 questions have wrong answers or missing correct options → explains why no model crosses ~92-93%.

2. **Contamination**: Since the dataset has been public since 2020, it's highly likely that this data has leaked into the **training data** of virtually every modern LLM, inflating scores.

3. **Prompt Format Gaming**: Extremely sensitive to system prompt wording — many frontier labs exploited this to boost scores.

> **Best Practice**: To get reliable comparisons, keep ALL conditions identical: no CoT, 5-shot prompting, temperature=0, same system prompt across models being compared.

## 🔍 MMLU — Dataset Curation Criteria {#mmlu-criteria}

**How were the 14,000 questions selected?**

The goal was to test **breadth of knowledge**, so the process was:
1. First, decide which **subjects** to include (57 subjects across 4 categories: **Humanities, Social Science, STEM, Others**)
2. Then source questions from the most **credible sources** for each subject

### Criteria (not very strict back in 2020):
- Must be a **valid question**
- Must have **4 options**
- **Correct answer** must be known
- Must be connected to a **specific field**
- Bonus points if sourced from a **reliable source** (real exam, textbook) or submitted by a **subject matter expert**

> Compare this to newer benchmarks
